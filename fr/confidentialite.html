Politique de confidentialité de VISDEX

Dernière mise à jour : 23 novembre 2026

En bref : VISDEX est une application de journal de pêche. Votre emplacement exact et vos coins de pêche sont privés par défaut, et vous choisissez vous-même ce que les autres voient de vos prises. Nous ne vendons pas vos données. Vous ne recevez d’e-mails marketing que si vous y consentez vous-même. Vous pouvez supprimer vous-même votre compte et vos données à tout moment dans l’application.

1. Qui nous sommes

VISDEX (« nous ») est établi aux Pays-Bas et inscrit à la Chambre de commerce néerlandaise (Kamer van Koophandel) sous le numéro 86629409. Nous sommes le responsable du traitement des données personnelles traitées via l’application VISDEX. Pour toute question sur la confidentialité et pour exercer vos droits (voir 9), écrivez à info@visdex.nl.

2. Comment lire cette politique

Au point 3, chaque traitement est décrit dans un bloc fixe : ce que nous traitons, pourquoi, sur quelle base juridique, qui reçoit les données et combien de temps nous les conservons. La base juridique est à chaque fois l’une des quatre bases suivantes de l’article 6 du RGPD :

  • Contrat : nécessaire pour vous fournir l’application que vous utilisez.
  • Consentement : uniquement si vous l’avez donné vous-même. Vous pouvez toujours le retirer, sans conséquence pour le reste de l’application.
  • Intérêt légitime : un intérêt de notre part ou d’autres pêcheurs, qui est à chaque fois indiqué dans le bloc. Vous pouvez vous y opposer (voir 9).
  • Obligation légale : lorsque la loi nous impose quelque chose.

Si un bloc n’indique pas de durée de conservation propre, nous conservons les données tant que votre compte existe. Ce qui se passe lorsque vous supprimez votre compte est décrit au point 8. Sous « Qui », nous indiquons des catégories de parties ; les entreprises concernées figurent sur la page Les tiers avec lesquels nous travaillons (voir 5).

Pour un compte, vous n’avez besoin que d’une adresse e-mail et d’un nom d’utilisateur. Tout le reste, vous le renseignez vous-même si vous le souhaitez. Si vous ne renseignez pas votre date de naissance, nous vous traitons comme une personne mineure et certaines fonctions sont désactivées (voir 4).

3.3 Ce que les autres voient de vos prises

Pour chaque prise, vous choisissez l’un de ces trois modes :

  • Public : la prise figure dans le fil Découvrir, avec l’espèce, la longueur, la photo et la province. Si vous avez 18 ans ou plus, une nouvelle prise est par défaut dans ce mode, sauf si vous désactivez « Nouvelles prises publiques par défaut ».
  • Compétitif : la prise compte pour les classements et les records, sans plan d’eau ni province, et ne figure pas dans le fil Découvrir. En dessous de 18 ans, une nouvelle prise est par défaut dans ce mode.
  • Privé : uniquement pour vous.
Quoi Fil Découvrir : uniquement pour les utilisateurs VISDEX connectés. Votre nom d’utilisateur, votre photo de profil et vos prises en mode Public. « Afficher mes prises publiques dans le fil Découvrir », sous Paramètres > Confidentialité, est activé par défaut ; si vous le désactivez, vos prises ne figurent pas dans le fil. Pour chaque prise, vous faites ce choix avec le mode. Au même endroit, avec « Nouvelles prises publiques par défaut », vous choisissez aussi si une nouvelle prise figure déjà dans le fil Découvrir au moment de l’enregistrement ; ensuite, vous continuez à choisir vous-même pour chaque prise. Avec « Toutes les prises en une fois », vous placez toutes vos prises en une fois dans le fil Découvrir, ou vous les en retirez toutes. Les prises qui comptent dans une compétition, un jeu-concours ou le Poisson de la semaine en cours restent alors telles quelles. Le partage public n’est possible qu’à partir de 18 ans.
Classements : par pays, et dans la Galerie d’honneur également une liste européenne avec le drapeau du pays associé à votre compte. Votre nom d’utilisateur, votre photo de profil et vos prises qui comptent. Vous n’y figurez que si vous activez vous-même « M’afficher dans le classement VISDEX » sous Paramètres > Confidentialité ; cette option est désactivée par défaut. Les classements sont aussi visibles sans compte VISDEX, par exemple sur visdex.nl.
Poisson de la semaine : vous participez avec les pêcheurs de votre propre pays.
Sur la carte : si vous activez « Placer cette prise sur la carte VISDEX » pour une prise, les autres utilisateurs VISDEX connectés voient sur la carte l’emplacement exact de cette prise, avec l’espèce, la taille, la date et le nom du plan d’eau. Ce n’est possible que pour une prise qui figure dans le fil Découvrir, et à partir de 18 ans. L’épingle n’apparaît qu’un jour après la prise, et pas pendant une période de fermeture pour cette espèce. Vous la désactivez à nouveau prise par prise. Personne d’autre ne voit les coordonnées de toutes les autres prises ni vos coins de pêche.
PourquoiPartager des prises avec d’autres pêcheurs et participer aux classements, si vous le choisissez.
Base juridiqueContrat. Ce que vous partagez, vous le choisissez vous-même avec les modes et les interrupteurs ci-dessus.
QuiLes autres utilisateurs, et, pour les classements, aussi les visiteurs sans compte. Notre service d’hébergement (voir 5).
Combien de tempsTant que la prise reste dans ce mode. Nous ne pouvons pas reprendre ce que quelqu’un a déjà vu.

Si vous partagez une prise dans Instagram Stories, l’application transmet l’image et l’identifiant public d’application de VISDEX à l’application Instagram de votre appareil. VISDEX n’envoie lui-même rien à Meta à cette occasion. L’application Instagram appartient à Meta, donc ce que vous partagez parvient ainsi à Meta ; ce que vous publiez ensuite sur Instagram relève des conditions d’Instagram.

3.6 Météo et eau pour votre prise et votre session

QuoiLa météo lors d’une prise et au début d’une session, récupérée à partir de l’emplacement et de l’heure. Votre appareil envoie l’emplacement à notre propre serveur ; celui-ci arrondit les coordonnées avant de les transmettre à un service météo, à environ 10 kilomètres près pour l’un des services météo et à environ 1 kilomètre près pour l’autre. Les anciennes versions de l’application récupèrent encore la météo heure par heure directement depuis votre appareil. L’application récupère les marées auprès de Rijkswaterstaat (l’administration néerlandaise des travaux publics et de la gestion des eaux) avec uniquement le code d’une station de mesure, sans votre emplacement ; notre serveur y récupère les conditions de l’eau. L’application recherche le nom du plan d’eau et la province d’un emplacement via le service de cartographie de votre appareil (Apple sur iPhone, Google sur Android), avec les coordonnées exactes.
PourquoiDu contexte pour votre prise et votre session.
Base juridiqueContrat.
QuiDes services météo, Rijkswaterstaat, Apple ou Google (voir 5).
Combien de tempsNous conservons la météo avec la prise ou la session, tant que celle-ci existe.

3.8 Chiffres agrégés de la communauté

QuoiÀ partir des prises de tous les pêcheurs, nous établissons des chiffres agrégés sans noms, par exemple les espèces prises dans une zone, les plans d’eau populaires et les appâts qui fonctionnent. Vous les voyez sur les calques de la carte, et ils sont intégrés aux conseils (voir 3.16). Les prises en mode Public et en mode Compétitif comptent. Les prises en mode Privé ne comptent pas, pas plus que celles des pêcheurs qui activent « Garder mes prises hors des calques de la communauté » sous Paramètres > Confidentialité. Un chiffre n’apparaît que s’il repose sur au moins 3 prises d’au moins 2 pêcheurs différents. Pour certains aperçus, le seuil est plus élevé, par exemple 10 prises de 5 pêcheurs pour les plans d’eau populaires et 15 prises de 3 pêcheurs pour les conseils appâts.
PourquoiMontrer à tous les pêcheurs ce qui est pris et où, sans qu’un chiffre ne désigne un seul pêcheur ou un seul coin de pêche.
Base juridiqueIntérêt légitime : des informations utiles pour tous les pêcheurs. Vous vous y opposez avec l’interrupteur ci-dessus, ou prise par prise avec le mode Privé.
QuiToute personne qui utilise l’application, uniquement sous forme de chiffre agrégé. Notre service d’hébergement (voir 5).
Combien de tempsUn chiffre agrégé ne contient aucune donnée permettant de remonter jusqu’à vous et continue d’exister même après la suppression de votre compte (voir 8).

3.16 Fonctions IA que vous activez vous-même

Quoi Espèce et longueur à partir de votre photo : la photo de cette prise précise, réduite et sans les données cachées comme la position GPS. Avec Pro, cela se fait automatiquement dès que vous ajoutez une photo lors de l’enregistrement ; dans la version d’essai, uniquement si vous le demandez. Si vous demandez une longueur, également l’espèce choisie et ce qui figure sur la photo comme référence de mesure. Nous ne conservons pas la photo pour cette fonction, mais nous conservons ce que l’application a proposé et ce que vous en avez fait.
Conseils à partir de votre journal de pêche (plan de pêche par espèce, tendances de pêche, conseils de session, bilan de la semaine) : date et heure des prises, espèce, longueur, poids, appât, technique, nom du plan d’eau et météo correspondante. Pour les tendances de pêche et le bilan de la semaine, uniquement des chiffres cumulés. L’application crée automatiquement le bilan de la semaine lorsque vous ouvrez votre Collection ; le résultat reste sur votre appareil. Pour les conseils de session, sont aussi transmis ce que vous remplissez dans le formulaire (espèce cible, plan d’eau, province, date, moment de la journée, rive ou bateau et préférence d’appât) et la météo. En outre, des chiffres agrégés de la communauté (voir 3.8). Si vous avez moins de 16 ans, rien de ce qui indique votre emplacement n’est transmis : aucun nom de plan d’eau, aucune province, aucun nom de lieu et aucune marée, même pour vos propres prises. Le plan de pêche par espèce peut toutefois citer des plans d’eau où beaucoup de poissons de cette espèce sont pris dans votre pays ; ce choix ne dépend pas de l’endroit où vous êtes.
Conseils sur place (Pro, à partir de 16 ans) : votre emplacement est envoyé à notre serveur, qui recherche quel plan d’eau et quels éléments se trouvent tout près de vous, comme des roseaux ou un ponton. Seuls sont envoyés au service d’IA le type de plan d’eau et sa taille, ces éléments avec leur distance et leur direction depuis vous, des chiffres agrégés sur les appâts et les techniques (voir 3.8), le mois, si vous pêchez aux Pays-Bas et l’espèce que vous recherchez. Vos coordonnées, le nom du plan d’eau, un nom de lieu et votre province ne sont pas envoyés au service d’IA.
Conseil de coins et Waterscan (à partir de 16 ans ; encore à l’essai, ouverts uniquement à quelques comptes de test de VISDEX lui-même) : le conseil de coins envoie les noms des plans d’eau situés dans la distance choisie, avec cette distance, vos propres prises à ces endroits, le nombre de pêcheurs qui y pêchent et la météo du moment. Le Waterscan envoie une photo de l’endroit où vous voulez pêcher, réduite et sans les données cachées comme la position GPS, avec le nom et le type de plan d’eau selon la carte, la météo, la date et l’heure, et le nombre de vos propres prises dans un rayon de 500 mètres. Là aussi, vos coordonnées ne sont pas envoyées au service d’IA.
Aucune de ces fonctions ne transmet votre nom, votre adresse e-mail, vos notes ou vos messages de chat.
PourquoiVous donner une suggestion, un conseil ou un aperçu.
Base juridiqueContrat : les fonctions IA font partie du service que vous utilisez chez VISDEX, surtout de Pro. C’est vous qui choisissez de les utiliser ou non, avec l’interrupteur Paramètres > Enregistrer des prises > Fonctions IA. Il est désactivé par défaut, et vous le désactivez à nouveau à tout moment, sans conséquence pour le reste de l’application. Les fonctions IA fonctionnent à partir de 13 ans ; les fonctions qui utilisent votre emplacement (Conseils sur place, conseil de coins et Waterscan) seulement à partir de 16 ans, même si l’interrupteur est activé (voir 4). Si vous le désactivez, plus rien n’est envoyé au service d’IA pour ces fonctions. Nous enregistrons si et quand vous avez activé l’interrupteur.
QuiUn service d’IA, actuellement celui d’Anthropic, l’entreprise derrière Claude (voir 5).
Combien de tempsNous conservons votre plan de pêche et vos tendances de pêche, pour que vous puissiez les rouvrir. Nous ne conservons pas avec votre compte le bilan de la semaine, les conseils de session ni votre emplacement pour Conseils sur place ; nous ne conservons pas la photo du Waterscan. Pour contrôler la qualité, nous conservons environ 1 conseil de session sur 10 pendant 30 jours au maximum, séparément de votre compte : le texte, la langue, le pays, l’espèce et le nombre de jours à l’avance. Pour chaque utilisation, nous enregistrons le fait que vous avez utilisé la fonction, et quand, pour éviter les abus et les coûts inutiles (intérêt légitime).

3.17 Contrôle par IA pour les jeux-concours et les compétitions

QuoiLa photo de votre participation ou de votre prise qui compte pour un jeu-concours ou une compétition publique, réduite et sans les données cachées comme la position GPS. Pas de nom, d’adresse e-mail, d’emplacement ni de plan d’eau. Le service d’IA regarde s’il y a un mètre ruban sur la photo, si le poisson est posé à côté et quelle longueur on peut y lire.
PourquoiVeiller à l’équité des jeux-concours et des compétitions. Pour un jeu-concours, c’est toujours une personne qui décide. Pour une compétition, l’issue du contrôle détermine uniquement si une prise compte (voir 7).
Base juridiqueIntérêt légitime, le nôtre et celui de tous les participants : des jeux-concours et des compétitions équitables, sans fausses prises. Il n’y a pas d’interrupteur, et c’est indépendant des fonctions IA. Opposition : écrivez à info@visdex.nl, et une personne examine alors votre photo.
QuiUn service d’IA (voir 5). Uniquement à partir de 16 ans avec une date de naissance connue ; sinon, nous examinons la photo nous-mêmes ou une règle fixe s’applique.
Combien de tempsL’issue du contrôle, 90 jours au maximum après les résultats. Une décision concernant votre prise, tant que votre compte existe.

3.18 Contrôle des photos de prises contre les faux et les abus

QuoiLa première photo de chaque nouvelle prise publique ou qui compte pour un classement, réduite et sans les données cachées comme la position GPS, avec l’espèce de poisson. Pas de nom, de compte, d’âge, d’emplacement ni de date. Le service regarde si l’image a été créée par une IA, s’il s’agit d’une photo d’écran ou si elle provient d’internet.
Pourquoi Veiller à l’équité des classements, du fil Découvrir, du Poisson de la semaine, de la Galerie d’honneur et des compétitions. Cela s’applique à tous les âges, car la prise d’un jeune figure dans les mêmes aperçus que celle d’un adulte ; c’est pourquoi seule la photo avec l’espèce est transmise.
Photos pouvant choquer : le même contrôle vérifie aussi si une photo peut choquer d’autres personnes, par exemple du sang, un poisson vidé ou levé en filets ou des viscères, et si le poisson est mort ou a été gardé. Cela nous permet de tenir les photos pouvant choquer d’autres personnes à l’écart des aperçus publics, ou de les afficher floutées. Votre prise continue de compter dans le classement, et vous voyez toujours votre propre photo.
Base juridiqueIntérêt légitime, le nôtre et celui de tous les pêcheurs : des aperçus équitables, sans fausses prises. Il n’y a pas d’interrupteur. Opposition : écrivez à info@visdex.nl ; nous mettons cela en balance avec l’intérêt de classements équitables.
QuiUn service de reconnaissance d’images (voir 5).
Combien de temps L’issue du contrôle, 90 jours au maximum. Si une personne de VISDEX a dû examiner la prise, cet examen jusqu’à 90 jours après la décision.
Conservation de cette indication : ce que le contrôle indique à ce sujet, nous le conservons uniquement sous forme de code fixe (oui, non ou incertain), sans le reste du résultat ni aucun texte du service. Nous conservons ce code tant que la prise existe, afin que la photo ne devienne pas visible pour d’autres plus tard de manière inattendue. Si vous supprimez la prise ou remplacez la photo, le code est supprimé.

3.19 Service client (Aide et contact)

QuoiVos messages dans le chat avec VISDEX, les photos que vous joignez, nos réponses, le sujet, et les données techniques du moment où vous commencez une conversation : version de l’application, appareil et système d’exploitation, langue, taille de l’écran, taille du texte, si les notifications sont activées, si vous avez Pro et les rapports d’erreur récents sur votre appareil. Si vous écrivez dans une autre langue, nous conservons aussi la traduction.
PourquoiVous aider avec votre question. Seule l’administration de VISDEX lit ces messages. C’est vous qui commencez une conversation ; VISDEX ne vous demande pas de contact en dehors de l’application, ni votre numéro de téléphone ou votre adresse. Vous ne recevez de photos de VISDEX qu’à partir de 18 ans, avec une date de naissance renseignée.
Base juridiqueContrat : vous demandez de l’aide, et c’est ainsi que nous vous l’apportons, y compris dans une autre langue. C’est pourquoi cela est indépendant de l’interrupteur Fonctions IA.
Qui Notre service d’hébergement (voir 5). Si vous avez 18 ans ou plus, nous pouvons utiliser un service d’IA (voir 5) pour traduire votre message, retraduire notre réponse, nous proposer un projet de réponse et décrire une photo. Pour la traduction, seul le texte du message est transmis. Pour un projet de réponse, sont transmis : les messages de la conversation (la version néerlandaise lorsqu’elle existe, les photos uniquement sous forme de nombre), le sujet, la langue et le pays de votre application, le nombre de questions précédentes, la version de votre application, votre plateforme, les rapports d’erreur récents sur votre appareil, si vous avez Pro, et des nombres approximatifs, comme le nombre de prises par tranches, ainsi que les noms des cinq derniers moments que nous avons enregistrés de votre utilisation, avec une indication approximative de leur ancienneté. Pour la description d’une photo, seule la photo est transmise. Si elle contient quelque chose de personnel, comme une adresse e-mail sur une preuve d’achat, le service le voit aussi ; nous ne le reprenons pas dans la description. Ne sont pas transmis : votre nom, votre nom d’utilisateur, votre adresse e-mail, votre date de naissance ou votre emplacement. Ce que vous tapez vous-même dans un message est en revanche transmis. Une personne de VISDEX lit chaque projet et l’envoie elle-même ; l’IA ne vous envoie rien. Si vous nous remerciez, le projet peut proposer de clore la conversation ; c’est aussi une personne qui en décide. Pour chaque conversation avec un projet de réponse, nous enregistrons une seule ligne courte, sans données personnelles et sans texte de message : le type de question (bug, facilité d’utilisation, idée ou demande d’aide) et une phrase sur le sujet, afin d’améliorer l’application. Si vous avez moins de 18 ans ou si nous ne connaissons pas votre âge, nous n’envoyons pas vos messages et vos photos au service d’IA. Jusqu’au 16 novembre 2026, nous rédigions les projets de réponse via un abonnement Claude d’Anthropic, soumis aux conditions d’Anthropic applicables aux consommateurs. Depuis cette date, les messages des utilisateurs de moins de 18 ans ou d’âge inconnu n’y sont plus envoyés, et nous passons ensuite à l’API.
Combien de tempsJusqu’à 12 mois après le traitement d’une question. Si nous avons répondu et que vous ne réagissez pas pendant 14 jours, nous clôturons la question. Nous supprimons un projet de réponse qui n’est pas envoyé dans les 30 jours suivant son rejet ou son expiration. Nous enregistrons le fait qu’un projet a été créé et s’il a été utilisé. Nous conservons la description d’une photo avec votre message. Nous conservons la ligne sur le type de question 90 jours au maximum, et elle disparaît plus tôt si la conversation disparaît.

Si vous nous envoyez un message via WhatsApp, tant que ce numéro existe encore, WhatsApp traite votre message et votre numéro de téléphone selon ses propres conditions. Vous recevrez alors peut-être une réponse automatique qui vous renvoie vers l’application. Nous n’intégrons pas une telle conversation dans l’application ni dans notre base de données.

4. Enfants et jeunes

VISDEX peut être utilisé à partir de 13 ans. Si vous pensez que nous traitons des données d’un enfant de moins de 13 ans, écrivez à info@visdex.nl et nous les supprimerons. Si nous ne connaissons pas votre date de naissance, nous vous traitons, pour les règles ci-dessous, comme une personne de moins de 16 ans, et les fonctions IA ne fonctionnent pas (voir 3.16).

  • Moins de 18 ans : vous ne pouvez pas mettre une prise en mode Public. Seuls vos compagnons de pêche voient vos prises dans le fil Découvrir et votre profil. Vous ne figurez pas dans la Galerie d’honneur. Vous ne pouvez pas placer de prise sur la carte nationale, vous ne participez pas aux concours, et votre photo et votre nom n’apparaissent pas sur nos réseaux sociaux. Des restrictions s’appliquent aux contacts avec des adultes inconnus : vous ne faites partie d’un chat de groupe ou du chat d’une compétition que si chaque adulte qui s’y trouve est votre compagnon de pêche. Le service client n’envoie pas vos messages et vos photos au service d’IA, et vous ne recevez pas de photos de VISDEX dans le chat.
  • Moins de 16 ans : vous ne recevez ni e-mails marketing, ni offres commerciales, ni bouton vers la newsletter d’un partenaire promotionnel. Les fonctions IA font partie de Pro, y compris le bilan de la semaine ; rien de ce qui indique votre emplacement n’est alors transmis, et le service d’IA reçoit la consigne de s’en tenir à la pêche et de ne rien conseiller de dangereux. Conseils sur place, le conseil de coins et le Waterscan utilisent votre emplacement et ne sont disponibles qu’à partir de 16 ans (voir 3.16). Lors des jeux-concours et des compétitions, votre photo n’est pas envoyée au service d’IA (voir 3.17). Vous pouvez en revanche découvrir et acheter Pro vous-même via Apple ou Google ; demandez d’abord l’autorisation à un parent, la boutique peut demander l’accord de votre parent. À partir de 13 ans, les fonctions IA sont incluses.
  • Classement : il est désactivé par défaut pour tout le monde. Si vous l’activez vous-même, vous figurez dans le classement avec votre nom d’utilisateur et vos prises qui comptent, y compris en dessous de 18 ans (voir 3.3).
  • Pour tous les âges : le contrôle des photos de prises contre les faux et les abus (voir 3.18), avec uniquement la photo et l’espèce.

Une partie qui travaille pour nous (un sous-traitant) le fait sur la base d’un accord de traitement des données et uniquement pour notre finalité. Il s’agit des catégories de parties suivantes :

  • Hébergement : notre base de données et notre stockage, dans l’Union européenne (Irlande).
  • Services météo, Rijkswaterstaat et service de cartographie de votre appareil : voir 3.6 et 3.7.

  • Notifications push et mises à jour de l’application : voir 3.11.
  • E-mail transactionnel : voir 3.13.
  • E-mail marketing : voir 3.14.

Pour chaque service d’IA que nous utilisons, la règle est la suivante : il n’utilise pas ce qu’il reçoit de nous pour entraîner des modèles d’IA et le supprime par défaut dans un délai de 30 jours ; si sa propre sécurité signale quelque chose comme un possible abus du service, il peut le conserver jusqu’à 2 ans.

Les entreprises concernées, leur siège, leur rôle et la garantie applicable figurent sur la page Les tiers avec lesquels nous travaillons. Vous y trouverez aussi les parties derrière visdex.nl.

Par ailleurs, la loi peut nous obliger à fournir des données, par exemple à la police ou à un juge (obligation légale).

7. Décisions automatisées

Deux contrôles peuvent décider automatiquement quelque chose au sujet d’une prise. Lors d’une compétition publique, le contrôle décrit en 3.17 peut déterminer qu’une prise ne compte pas. Le contrôle décrit en 3.18 peut retirer une prise des aperçus publics jusqu’à ce qu’une personne de VISDEX l’ait examinée. Vous voyez une telle décision sur la prise, avec le motif, et avec le bouton Demander un réexamen, une personne l’examine à nouveau. Votre prise elle-même, votre journal de pêche et les classements n’en sont pas modifiés, et une prise n’est pas refusée automatiquement. Nous ne créons pas de profil de vous à des fins publicitaires.

8. Si vous supprimez votre compte

Si vous supprimez votre compte sous Paramètres > Supprimer le compte > Supprimer mon compte, vos données personnelles, vos prises, vos photos, vos emplacements, vos messages et vos conversations avec le support sont supprimés immédiatement et définitivement, ainsi que votre contact chez le service d’e-mail marketing et une inscription à la liste d’attente ou à un jeu-concours sur visdex.nl avec la même adresse e-mail. Six choses continuent d’exister :

  • Les compétitions que vous avez créées vous-même et auxquelles d’autres ont participé, car sinon nous effacerions aussi leurs résultats. Vous y apparaissez alors comme « Utilisateur supprimé ». Si votre compétition n’avait pas d’autres participants, elle disparaît entièrement.
  • Une preuve que la suppression a été effectuée : uniquement un code chiffré irréversible et l’heure, sans nom ni adresse e-mail.
  • Le journal des décisions de l’administration de VISDEX : quelle action a été effectuée sur un identifiant de compte, avec l’explication et les données de cette action, sans date de naissance. Nous en avons besoin pour pouvoir vérifier les cas d’abus et de sécurité des enfants (voir 3.22).
  • En cas de signalement d’abus, l’instantané de la conversation signalée, avec les noms et les messages, jusqu’à douze mois après le traitement du signalement (voir 3.22).
  • Les données de paiement d’un abonnement (montant, produit, boutique et date), sans lien avec votre compte, car la loi nous oblige à les conserver (voir 3.10).
  • Des chiffres agrégés qui ne permettent pas de remonter jusqu’à vous (voir 3.8).

9. Vos droits

Vous avez le droit de :

  • consulter vos données ;
  • faire rectifier des données inexactes (vous modifiez aussi vous-même votre profil et vos prises dans l’application) ;
  • faire effacer vos données (vous-même dans l’application, voir 8) ;
  • faire limiter le traitement ;
  • récupérer vos données : dans l’application via Paramètres > Tes données et ton compte > Exporter mes données, ou sur demande ;
  • vous opposer à un traitement fondé sur l’intérêt légitime ; la manière de procéder pour chaque traitement est indiquée dans le bloc correspondant au point 3 ;
  • retirer un consentement : pour les e-mails marketing, via le lien de désinscription ou sous Paramètres > Notifications et e-mail. Vous désactivez les fonctions IA à tout moment via Paramètres > Enregistrer des prises > Fonctions IA (voir 3.16).

Envoyez votre demande à info@visdex.nl. Nous répondons dans un délai d’un mois. Vous pouvez également introduire une réclamation auprès de l’Autoriteit Persoonsgegevens (l’autorité néerlandaise de protection des données). Vous pouvez aussi vous adresser à l’autorité de contrôle de l’État membre de l’Union européenne où se trouve votre résidence habituelle ou votre lieu de travail, ou dans lequel la violation aurait été commise. En France, il s’agit de la Commission nationale de l’informatique et des libertés (CNIL).

10. Sécurité

Nous protégeons vos données par des connexions chiffrées et des règles d’accès dans la base de données, afin que seuls vous et les personnes avec qui vous partagez puissiez accéder à vos données. Les emplacements exacts sont conservés à part, avec une protection renforcée, et ne sont visibles par d’autres que si vous le choisissez vous-même (voir 3.3).
